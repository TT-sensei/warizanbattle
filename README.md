# わり算バトル

わり算の筆算を、ゲーム感覚で練習できる小学生向けの学習アプリです。

筆算の基本である「たてる・かける・ひく・おろす」の順番を、問題を解きながら身につけます。

## できること

- わり算の筆算問題に挑戦
- 「たてる・かける・ひく・おろす」の手順を1つずつ確認
- 筆算のマスに答えを入力して進めるステップ式学習
- わりザウルスなどのモンスターと戦うバトル演出
- 連続正解によるコンボ
- 最高コンボとクリア回数の記録
- ヒントを見ながらの再挑戦
- わり算学習の達成に応じたバッジコレクション

## 遊び方

1. バトルを開始します。
2. 画面に表示された筆算のステップを確認します。
3. 「たてる・かける・ひく・おろす」の順に答えを入力します。
4. 正解すると相手にダメージを与えられます。
5. 1問を最後まで解くと、次の問題へ進みます。
6. 5問のバトルをクリアして、記録やバッジを獲得します。

間違えても、筆算のマスやヒントを確認しながらやり直せます。

## 対象

- 小学校中学年から高学年
- わり算の筆算を学習している子ども
- 筆算の手順を確実に身につけたい子ども

## 記録について

最高コンボ、クリア回数、バッジの獲得状況は、使用している端末のブラウザに保存されます。
